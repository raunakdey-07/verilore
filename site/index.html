From Markdown to a prompt you can trust.

  1. 01Write it downRules and facts in Markdown, one bullet each.
  2. 02Review itMark documents draft, approved or rejected. Corrections keep the old version.
  3. 03Ask for a packYour app gets the approved lines for the task, each with its source.
step 03 · app.py
from verilore import Verilore

vl = Verilore("trailhead", base_url=URL, api_key=KEY)
pack = vl.memory.pack(
    query="",
    path_prefix=["brand", "campaigns/spring"],
)
pack.current_memories
