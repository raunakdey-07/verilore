# Channel rules

Each channel has its own length and its own limits. When a channel is not listed
here, follow the email rules.

| Channel | Length | Emojis | Hashtags |
|---|---|---|---|
| Instagram | 150 characters | 2 at most | 3 at most |
| LinkedIn | 120 words | none | none |
| Email | 200 words | none | none |
| WhatsApp | 60 words | 1 at most | none |
| Blog | 800 words | none | none |

## Instagram

- Always end an Instagram caption with the estate name in capitals.
- Never tag a competitor brand on Instagram.

## WhatsApp

- Send WhatsApp messages only to customers who opted in.
- Every WhatsApp message must include the word STOP so a reader can unsubscribe.
